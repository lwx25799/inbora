# inbora HTML 交互原型

入口：项目根目录的 **Inbora原型.html**。双击即可离线打开，无需安装、构建或启动后端。移动或分享时，请将该文件与 `prototype` 文件夹放在同一目录。

依据 `Inbora_UI_效果图合集` 的 10 张参考图制作，包含 9 个导航页面。第 02、03 张对应同一个会话中心及其人工回复状态。

| 页面 | 可体验的操作 |
| --- | --- |
| 工作台 | 趋势范围切换、告警详情、跳转会话与账号 |
| 会话中心 | 通道/状态/账号筛选、搜索、会话切换、独立草稿、使用 AI 建议、模拟发送 |
| 账号管理 | 筛选、分页、新增与编辑演示账号、批量自动回复开关、详情 |
| 自动回复 | 规则分组、触发条件、执行动作、独立编辑内容、关键词模拟 |
| 知识库 | 分类、全文搜索、文档预览、新建/编辑 FAQ、发布/停用、TXT/MD 本地导入 |
| AI 配置 | 提示词、人设、风格、边界、示例模型服务商、预设答复模拟 |
| 任务调度 | 浏览器池筛选、任务详情、暂停/恢复演示队列 |
| 数据统计 | 日期与账号分组切换、数量/占比切换、演示 CSV 导出 |
| 系统设置 | 设置分类、演示选项保存、模拟备份/连通性检查、诊断说明导出 |

## 视觉实现

保留参考图的浅灰蓝底色、白色面板、蓝灰色选中态、紧凑指标及三栏会话布局。字体使用系统 Segoe UI 与微软雅黑，图标使用本地 Feather SVG 子集。页面适配桌面和窄屏，表格在自己的容器内横向滚动。

头像采用本地文字标识，作品区采用明确占位，不使用参考图片的裁切或拼贴。示例内容可在 `inbox.js`、`management.js`、`config.js`、`overview.js` 中替换。

## 演示边界与保存

- 仅有本地界面状态；不连接抖音、现有 inbora 后端或模型提供商。
- 发送、AI 测试、同步、备份与检查均为模拟，未实现真实业务服务。
- 草稿经“保存草稿”保存在当前浏览器；系统偏好经“保存设置”保存在当前浏览器。
- 账号、文档、规则编辑和模拟发送只保留到当前页面刷新。AI 保存按钮说明为“本次原型会话”。
- 不读取真实 Profile、数据库、凭据或私人消息；不会保存 API Key。
- HTML 的内容安全策略禁止网络连接，不依赖 CDN、在线字体或外部头像。
- 多账号数据用于展示效果图中的规划，不表示当前应用已有这些运行能力。
