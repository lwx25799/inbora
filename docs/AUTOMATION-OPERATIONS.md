# inbora 0.3.x 过渡版操作与恢复手册

> **适用界面范围**：本文档对应当前过渡版 3 页桌面界面（`desktop/src/`，已合入阶段 2 多模型管理与阶段 3 最小账号面板）。阶段 5 按 [品牌标识与阶段 5 前端视觉规范](../assets/brand/BRAND-AND-UI-SPEC.md) 替换为 9 页正式工作台后，各入口将迁至独立页面，底层安全与恢复合同保持不变。

---

## 一、启动、开发重载与运行边界

- **日常开发入口**：使用项目根目录 `启动inbora.cmd`（存在私有开发脚本时自动注入已授权固定运行目录；否则执行 `pnpm desktop:dev` 并由连接页打开既有私有运行目录）。仅用户明确要求时才执行 `pnpm desktop:build` 构建安装包。
- **热更新与安全重载**：前端在 `127.0.0.1:1420` 热更新；Node `src/` 变动时只安全重载 Sidecar（先关闭旧进程输入、等待在途收尾并释放目录与 Profile 锁，再启新进程）；仅 Rust 或原生配置变动时重编开发调试壳。
- **单持有者与默认无头静音**：单账号连接后持续持有专属无头静音 Edge Profile，正常重启自动恢复在线并保留首次运行起点、水位、预算、未知记录与「自动回复：开／关」持久化选择。真正退出应用后停止收取并释放持有者。
- **GUI 实测分工**：实机 GUI 交互、扫码登录与安全验证由用户本人操作，禁止使用 Computer Use 或桌面自动化工具。

## 二、日常操作清单

1. **收取范围与轮询**：在左侧「AI 与设置 → 后台收取与持续授权」分别启用评论和私信收取并保存。默认评论每 30 秒、私信每 15 秒轮询一次（双通道串行、每轮有界窗口、人工发送优先）；单对象失败按 120 秒冷却让出，普通错误退避上限默认 10 分钟，不伪造成功水位。
2. **统一自动回复开关**：使用「AI 与设置」顶部或主栏的「自动回复：开／关」。关闭后停止新的自动模型生成与未提交策略发送，但保持账号在线、双通道收取、人工回复及已提交回读；重启后保持关闭状态。
3. **收件箱与人工回复**：
   - 收件箱提供「未读」「等待回复」「需人工查看」「已回复」「全部消息」筛选，日常不要求领取、预检或二次确认。
   - 私信选中后聚焦输入框即自动接管、续租并保稿；评论保留一级根评论与楼中楼上下文，点「打开人工回复」弹窗编辑。
   - 点击一次「发送」或按 `Ctrl+Enter` 提交，连续多句独立排队由唯一 `SendCoordinator` 依次单次提交并回读确认；切换目标、后台刷新或迟到回调绝不覆盖未保存人稿。
   - 图片/表情在后台生成本机受限 PNG 预览（不送模型、不把外部 URL 交给前端）；分享视频/图集提供原链接复制；媒体与分享消息允许人工查看后直接输入并发送文字。
4. **多模型连接与全局切换（阶段 2）**：
   - 在「AI 与设置 → 当前模型 / 提供商管理」配置模型连接（支持 DeepSeek、OpenAI、Claude、Gemini、通义千问、豆包、硅基流动、OpenRouter 与自定义云端）。
   - 保存只更新待应用修订，点击应用切换全应用唯一当前模型（SQLite `m_selection`），人工建议、自动回复、知识分析与试答统一沿用；连接测试消费一次全局 MODEL 预算，业务生成禁止自动重试。
   - Key 留空保存保留当前内存 Key（重载后会丢失需补填）；勾选「在本机安全保存 Key」走 Windows CurrentUser DPAPI（默认关闭，删除入口同时删密文与清内存，换用户或机器不可解密）。详见 [多模型提供商 V1.0 路由契约](MODEL-CONTRACT.md)。
5. **持续授权、楼中楼与额度**：在「后台收取与持续授权」配置账号、通道、模型、作品/会话范围、屏蔽词、回复规则、时段与额度（支持有限或「无上限」`null`，累计已用始终保留）；「自动回复楼中楼评论」默认开启，仅对具备准确网页资格的子评论生效。
6. **单库多账号面板（阶段 3 过渡入口）**：在「AI 与设置 → 账号与平台（单库多账号）」查看 `schema4` 下的账号列表与状态（活跃 / 暂停 / 异常 / 已解绑）及执行解绑（保留历史档案不删库）；`schema3` 单账号库仅提示单账号模式。真实多平台接入按阶段 4 分批启用，新账号默认关闭自动外发。
7. **后台浏览器资源监测**：在「AI 与设置 → 运行诊断 → 后台浏览器资源」每 60 秒采样本 Sidecar 后代 Edge 进程工作集与私有提交量（不含系统普通浏览器，150 秒无样本标为过期；脱敏报告存于私有目录 `reports/browser-resources.json`）。

## 三、页面安全验证、有头查看与全局急停

- **原无头页内安全核验（首选）**：命中未校准可见安全组件时，仅暂停受影响通道（另一正常通道继续运行；屏外/隐藏空壳不误报）。点击顶部「处理原验证页面」，在客户端弹窗内直接查看无头原文档实时画面并完成受限指针/键盘核验，不切换模式、不重建页面、不自动求解；通过后解除绑定版本的通道暂停。
- **有头浏览器查看与登录恢复**：仅平台明确要求重新登录（`LOGIN_REQUIRED`）或本人主动点「查看这条消息」/「打开有头浏览器」排查时，临时切至静音有头窗口并保留原故障页与网页人稿；完成后关闭窗口或点「返回无头运行」/「返回无头并检查恢复」。
- **全局急停（持久不自解）**：账号变化、来源矛盾、平台明确停止或主动在「系统设置 → 故障处理」触发急停时，立即冻结全部调度与外发，重启、普通重连或保存配置均不解除；必须核验原账号、专用页面与安全门禁后显式点击「检查并恢复运行」方可解除，且绝不重发旧未知记录。

## 四、本机助手连接（MCP）

`inbora` 内置可信本机 stdio MCP 入口，复用客户端已有账号范围、累计额度、模型许可与唯一 `SendCoordinator`，客户端未运行时返回 `APP_NOT_RUNNING`。入口在「AI 与设置 → 本机助手连接（MCP）」，仅提供「停用／启用助手连接」（停用持久生效，重启不恢复）。

| 工具 | 用途 |
| --- | --- |
| `inbora_get_status` | 无正文的运行目录、后端实例、浏览器、同步、预算和连接摘要 |
| `inbora_list_inbox` | 按现有筛选分页查询已收取范围，每页 20 条 |
| `inbora_get_thread` | 按准确 eventId 读取有限详情，时间线每页最多 30 条 |
| `inbora_get_diagnostics` | 聚合数量和安全原因码，无正文、目标标识或原始日志 |
| `inbora_inspect_preview` | 准确消息的预览状态、尺寸和原因，不返回图片、文件路径或 URL |
| `inbora_sync_inbox` | 复用现有同步，返回 runId，从状态查询进度 |
| `inbora_mark_all_read` | 仅标记当前范围已存在记录，新入站仍未读，不改变回复状态 |
| `inbora_set_automatic_reply` | 开关现有自动回复政策，不创建政策或提高应用额度 |
| `inbora_refresh_preview` | 对准确媒体记录排队刷新，结果仍用预览诊断查询 |
| `inbora_emergency_stop` | 持久全局急停；MCP 无恢复急停工具 |
| `inbora_open_reply` | 取得准确文字目标、selectionId、接管代际、草稿及上下文版本 |
| `inbora_save_draft` | 按准确版本保存为 `MCP_ASSISTED` |
| `inbora_generate_suggestion` | 依已有模型许可、Key 和应用额度生成一次建议 |
| `inbora_send_reply` | 沿用唯一发送协调器、持久意图及送达核验，单次提交 |
| `inbora_get_operation` | 查询已接收的 `operationId`，断线/重启不重放；停用后隐藏旧正文 |
| `inbora_close_reply` | 释放助手自己的准确接管，保留草稿 |

- **写操作合同**：写工具必须传调用前保留的 UUID `operationId`；GUI 正在编辑时助手不能抢占；首版仅代发可靠文字事件，媒体/分享不向助手开放。超时或断线后只能查 `inbora_get_operation`，严禁换新 ID 重发；`UNKNOWN` 保留未知并禁重发。
- **本机安装与卸载**：在 `%USERPROFILE%\.codex\config.toml` 配置 `mcp_servers.inbora` 指向已验 Node 路径、`<项目根>\dist\mcp\stdio.js` 与 `--runtime <私有运行目录>`（连接凭据存于运行目录 DPAPI，重启轮换、退出失效）。卸载前先点「停用助手连接」，再移除或禁用 Codex 配置，不删除历史库与意图记录。

## 五、异常恢复与数据库备份边界

- **未知结果（`UNCERTAIN`）与有界补证**：暂未取得完整回执的意图在事务内登记有界只读补证（最多 2 次、单次 30 秒时限、恢复窗 120 秒）；重启只做只读补证，绝不自动重发；已开始的模型任务转待核对，不自动重试付费调用。
- **读取失败与退避**：单作品/单会话失败保留原成功水位并冷却让出；评论无法证明的单行隔离待核对，不让模型猜补正文；剩余读取失败按通道记录一次脱敏几何报告 `evidence/collection-read-*.json`（无正文、输入值或原生 ID）。
- **数据库备份与回退红线**：升级前必须用 SQLite 在线 Backup API 生成一致备份（存放在私有运行目录 `backups/`），并在私有副本验证升级与恢复。恢复备份前须完全退出应用确认释放目录与 Profile 锁，且保留当前库及全部 `WAL/SHM` 证据；**已发生真实外发后严禁用旧快照覆盖清除意图、收据或已消费额度**。
