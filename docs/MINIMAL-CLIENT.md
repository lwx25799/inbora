修订日期：2026-11-06。依据用户提供的[正式版实施与人工回复方案V2.1](../Inbora_正式版实施与人工回复方案_V2.1_2026-11-06.md)，将最小客户端定位为单账号人工客服工作台与AI辅助入口，是正式版S1/S2的最小可复用子集。

用户已要求基于当前测试进度提前开发，取消“必须GO后才启动客户端”的时序限制。客户端开发与P0—P4验收并行；浏览器PoC、工作台人工发送、AI接入和原生包分别验收，不能互相替代。M1/M2与M3离线实现已接通，Windows10原生包已构建/安装/启动，QA原生交互已验证；M4、真实DeepSeek与Windows11仍未完成。最新逐项证据见[CLIENT-ACCEPTANCE](CLIENT-ACCEPTANCE.md)，不以历史未完成草稿作为交付能力。

## 2. 最小界面与两条操作链路

采用浅色客服收件箱，左侧单账号及运行状态，中间评论/私信待办，右侧准确目标、上下文和统一编辑器；设置、审计使用同一窗口页签。最小窗口900×640、常规1240×800，长文可滚动，目标与完整批准文本不得因窗口缩小而隐藏。

| 区域 | 必须提供的内容 |
| --- | --- |
| 收件箱 | 全部/评论/私信，待处理/待审批/待人工/待核实筛选；实际发现来源、最后成功同步与分页，不伪报实时在线 |
| 私信详情 | 有限已观察聊天时间线、稳定对方身份、消息方向与原事件，上下文仅取准确会话 |
| 评论详情 | 作品链接、准确父评论ID、作者、原文及楼中楼上下文；区分通知和作品补充发现，不画成私聊 |
| 统一编辑器 | 没有AI草稿时也可直接输入、保存、清空；生成/引用AI建议、修改、拒绝；显示来源、版本与字数 |
| 人工操作 | 接管、续租/释放、暂停、明确确认发送；接管者、禁用原因和完整目标/全文，本期无自动发送 |
| 账号与运行 | 登录核验、浏览器启停、受测模式、最近同步、需验证/异常；全局急停始终可操作 |
| AI与审计 | DeepSeek、人设/业务说明/规则、预算、Token、脱敏错误及发送/接管/审批记录；未知回执只读核验 |

**纯人工链路**：选事件 → 查看准确目标 → 人工接管 → 直接输入并保存 → 核对目标/全文并明确确认 → Node单次提交 → 回读后显示已确认。无需设置Key，无模型请求，不产生模型Token。

**AI辅助链路**：选事件 → 显式生成建议 → 引用/编辑为当前草稿 → 人工接管与批准 → 同一发送协议 → 同一回读证明。保存/编辑不触发模型；模型建议不能覆盖期间产生的新人工版本。

先实现OBSERVE、DRAFT_ONLY、MANUAL、AI_ASSISTED四种模式；首次接入或能力未核验强制DRAFT_ONLY。MANUAL仅在用户主动请求建议时调用AI。LIMITED_AUTO不进入本期界面或后端发送许可。

## 3. 能力门禁与状态呈现

Node按账号、通道、浏览器模式保存READ_OK、SEND_REVIEW_ONLY、SEND_AVAILABLE、BLOCKED状态及证据引用、核验时间和失效时间。能力有效期初始24小时，映射/账号/浏览器版本变化或安全验证立即失效；缺证据、过期或身份变化则降级。前端切换模式不能开通发送。受控实机校准使用单独显式入口，每条仍批准，不用于绕过日常能力门禁。

评论和私信分别开放；内核发送通过不等于工作台人工发送通过。GO-MANUAL-DM、GO-MANUAL-COMMENT、GO-HUMAN-TAKEOVER与PoC GO分别报告。

| 工作台状态 | 操作边界 |
| --- | --- |
| 可人工回复 | 当前权限、强目标核验、通道能力、接管租约、版本、暂停及冻结检查全通过后才允许确认 |
| 目标需核对 | 可保存草稿/打开已授权原对象；发送禁用，不能仅凭昵称/同文放行 |
| 账号异常 | 保留草稿，提示登录/验证码/页面变化等原因，不自动重登后重发 |
| 排队/预检 | 显示内核进度；内容为不可变快照，唤醒失败或等待超过60秒则退回重新确认 |
| 发送中 | 禁止重复点击；急停不能伪报已撤回，已存意图继续回读或冻结 |
| 已确认 | 须准确原目标、我方全文和可信收据，不以清空输入框、HTTP200或点击成功判送达 |
| 结果待核实 | 冻结同目标外发，提供只读核验；无一键重试，不改写旧未知收据 |
| 发送前失败 | 仅有证据证明意图未持久化且未开始点击时使用；修复后重新核验批准 |

2026-11-07用户调整私信回读合同：平台与本机时间差几百毫秒不单独判失败，允许最多2秒偏差；须准确账号/会话/我方/全文/确认状态、唯一最新端原生ID、剔除该新记录后上下文摘要与发送前批准相同，并在空编辑器正常刷新后两次同ID一致。请求关联证明仍独立可用，不补造历史ack。旧异常记录保留，新的只读核验另记，不自动重发或批量解除未知。

## 4. 共用内核及必须补齐的业务合同

```text
React收件箱/编辑器 → Tauri受限IPC → Node应用服务
CLI ─────────────────────────→ 同一应用服务
                                  ↓
                 操作员/能力/接管/版本与唯一发送协调器
                                  ↓
                    SQLite + AccountActor + 已有适配器
```

复用ProfileOwner、AccountActor、EventStore、generateDraft、SendCoordinator及两通道适配器。先按职责增加src/app、统一契约及desktop，不为符合目录图搬迁全仓或建立第二套调度器；正式版拆包时迁移路径，保留业务合同和数据兼容。

1. **操作员身份**：Node为当前本机授权会话生成操作员ID及短期凭据，绑定唯一账号和可读/编辑/批准/发送权限。前端传入的operatorId不作为权威；本期无多人账号管理，但后端必须校验身份和权限。
2. **目标接管**：按accountId + channel + targetKey持久化接管者、generation和租约；租期120秒，持有编辑器时每30秒续租。接管/释放/账号暂停递增代际并撤销未点击审批；过期命令拒绝，未知不解除。
3. **草稿版本**：人工可从空草稿开始，保存带expectedVersion；AI返回时若版本已变只作为候选，不覆盖人稿。来源区分HUMAN_TYPED和AI_ASSISTED_APPROVED，审批绑定目标、全文、版本和代际。
4. **持久幂等命令**：一次明确确认生成稳定commandId，双击/重连复用；Node存命令及不可变参数摘要。同ID同参数返回原结果，不同参数拒绝，与同来源事件唯一发送意图约束整合，不因版本变化再点击。
5. **最终门禁**：CLI和GUI均检查当前权限、接管代际、草稿/上下文版本、能力、急停和未知冻结；排队后及持久意图前重核。切换消息使旧预检确认失效，传输重连不自动提交。
6. **急停与恢复**：急停走独立控制路径，不能排在浏览器/模型任务后。未存意图的发送失效；已存意图继续确认或冻结。关闭不删除数据，重开不恢复旧发送命令执行。

IPC使用协议版本、请求ID、结果与状态事件。首批业务命令为getInbox/getThread、claimHuman/renewHuman/releaseHuman、saveDraft/generateSuggestion、previewSend/submitManualSend/getSendResult、pause/resume、reconcileUncertain(READ_ONLY_VERIFY)。订阅send_status_updated/takeover_updated；重连读取权威快照，不能重放命令。语义对齐V2.1第17章，实际Zod契约与现有类型一起审查。

接管、版本、权限及幂等元数据与send_intents在SQLite事务内关联。显式迁移现有数据库版本，先在私有复制库验证升级/恢复再触碰实机库；保留原基线、水位、暂停、预算、审批、意图、收据及异常。本期仅只读核验未知，不实现MARK_NOT_SENT解冻或扩展旧未知重试。

## 5. DeepSeek与凭据

用户已选择DeepSeek。采用[官方Chat Completions接口](https://api-docs.deepseek.com/api/create-chat-completion)，默认地址https://api.deepseek.com/chat/completions，初始模型deepseek-flash，允许配置用户可用的官方模型；依据[官方接入页](https://api-docs.deepseek.com/)核对，不沿用过时别名推定可用。

独立适配messages、choices和usage，不把现有HttpDraftProvider自定义JSON契约换地址冒充兼容。非流式、输出上限512 Token、30秒超时、无自动重试；调用前持久预占预算。保留有限同目标上下文、敏感信息阻断、输出校验及重复输出检查，AI失败仍可人工编辑。

Key在客户端密码框输入，传给后端后清空界面，默认仅后端本次进程内存保存，退出后重输。若增加“记住密钥”，先落实Windows凭据存储/DPAPI；不写明文配置、SQLite、日志或仓库。非密钥配置保存私有目录。已有50次模型/20次发送上限继续累计；选择供应商或填Key不等于调用授权。
