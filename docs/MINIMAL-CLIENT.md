# GO 后最小图形客户端

2026-11-06用户明确要求：P0—P4实机GO后，交付最小图形客户端用于接入AI并试用完整链路，保留向正式版扩展的结构。此要求替代原P5“仅集成评审”。当前处于范围确认，客户端尚未实现，GO尚未完成。

## 交付与使用流程

交付本机Windows 10专业版x64 Build19045可安装或解压启动的Tauri v2 + React客户端。日常试用无需终端命令；扫码、验证码或人工接管通过受控可见浏览器完成，客户端显示对应状态。

| 功能 | 最小行为 |
| --- | --- |
| 账号与运行 | 显示唯一被测账号、登录/运行状态；启动、暂停、恢复；显示需要人工验证或接管的原因 |
| AI配置 | 配置一家具体验证供应商的HTTPS地址、模型和API Key，以及回复身份、业务说明和回复规则；显示授权、调用预算及错误摘要 |
| 消息与草稿 | 按评论/私信查看已授权范围内的新事件、准确原目标和有限上下文；生成、编辑、拒绝草稿 |
| 审批与发送 | 展示完整文本和准确目标，由用户明确批准后单次发送；编辑使原批准失效，界面不能跳过内核门禁 |
| 回执与恢复 | 展示待审批、发送中、已确认、未知及需人工核对状态；暂停接管可用，重开客户端可继续查看原任务和收据 |

试用必须通过图形界面走通：配置AI → 授权范围内采集评论/私信 → 真实模型生成草稿 → 人工编辑/批准 → 单次提交 → 准确回读与状态展示。两通道分别留存实机证据；Mock只用于预检，不替代这轮真实AI试用。

真实供应商尚未选定，选择由用户提供的供应商、接口、模型及明确调用授权确定；实现时先核对其官方契约及相关开源适配，再完成一家具体验证，不承诺任意“兼容接口”都可直接接入。当前`HttpDraftProvider`是本项目自定义JSON契约，不能仅更换地址就宣称适配成功。已有50次模型/20次发送上限继续累计，不在客户端上线时重置，亦不构成调用或发送授权。

## 共用内核与正式版扩展

```text
React界面 → Tauri受限命令 → Node sidecar业务服务
CLI ─────────────────────→ 同一套业务服务
                            ↓
                   现有Store / AccountActor / 浏览器适配器
```

- 保留现有Node/TypeScript内核，按需抽出CLI与sidecar共用的应用服务；前端不解析CLI的人类可读输出，不复制去重、审批、发送或回执逻辑。
- sidecar使用带协议版本、请求ID的结构化命令/结果和状态事件；采用stdin/stdout传输，日志走脱敏stderr。Tauri后端只允许必要命令，不向界面开放任意shell、数据库或Profile访问。
- 账号仍只有一个内核持有者、一个Profile和两个专用Page；图形界面与CLI同时启动时沿用排他门禁，重连或进程重启不得重提旧发送意图。内核退出即停止该实例操作，不静默创建第二持有者。
- 发送批准绑定准确任务、目标、全文和版本，继续执行先持久意图、一次点击、可信回读、未知冻结。GUI中的人工批准即该条批准，不再额外叠加聊天确认；批准文本/目标变化须重新批准。
- 继续使用既有私有运行目录及数据库，安装目录与运行数据分离；必要的版本迁移显式验证，保留原审批、意图、收据、预算和暂停状态，不另建一套GUI业务库。
- API Key输入后仅传给后端并保留在本次进程内存，界面清空该值，不写明文配置、日志或数据库；非密钥配置保存在私有运行目录。关闭后重新输入Key即可继续试用，本期不增加密钥管理系统。
- 正式版可增加界面和应用服务命令，继续复用同一内核；本期不做多账号调度、复杂RAG、插件平台、云同步或完整运营工作台。
